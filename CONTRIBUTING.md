# Contributing

Thank you for considering contributing to Laravel Cafe Blog.

## How to contribute

1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/ma-fonctionnalite`.
3. Make your changes and write tests if applicable.
4. Run the test suite: `php artisan test`.
5. Ensure code style is consistent: `./vendor/bin/pint`.
6. Commit with a clear message following [Conventional Commits](https://www.conventionalcommits.org/).
7. Open a Pull Request against the `main` branch.

## Code style

This project follows the PSR-12 coding standard enforced by Laravel Pint.

```bash
./vendor/bin/pint
```

## Reporting issues

Open an issue on GitHub with:
- A clear description of the problem.
- Steps to reproduce.
- Expected vs actual behavior.
- PHP and Laravel version.
